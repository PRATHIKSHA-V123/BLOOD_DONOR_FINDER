# RaththamTN: Tamil Nadu Blood Donor Network
1. pgAdmin: Query Tool on database `lifelink`, paste schema_pg.sql, press F5 (200 donors, 38 districts, 44 hospitals).
2. Put your PostgreSQL password in app.py (YOUR_PASSWORD).
3. `pip install -r requirements.txt` then `python app.py`, open http://127.0.0.1:5000
Admin login: admin / admin123
